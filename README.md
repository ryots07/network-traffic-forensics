# network-traffic-forensics
Network Traffic Forensics is a practical cybersecurity project focused on analyzing network traffic and identifying indicators of potentially suspicious activity.

The project was conducted in a controlled Kali Linux environment using Wireshark and TCPdump, with supporting tools such as nslookup and curl.

The investigation covers live packet capture, DNS analysis, TCP connections, SYN/SYN-ACK behavior, TLS traffic, retransmission analysis, TCPdump-based inspection, and protocol hierarchy analysis.

Rather than assuming that unusual-looking traffic is malicious, the investigation follows an evidence-based approach: capture → filter → inspect → correlate → assess → report.

The final assessment is based on the traffic captured and reviewed during the practical investigation, with observations, packet counts, filters, commands, and findings documented throughout.
